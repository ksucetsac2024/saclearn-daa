1. Master Theorem Quick Lookup

For recurrences of the form T(n) = aT(n/b) + f(n) where a ≥ 1, b > 1, compare f(n) with nlogb a:

Case Condition Polynomial Gap Solution T(n) Classic Example
Case 1 f(n) = O(nlogb a − ε) f(n) grows strictly slower Θ(nlogb a) T(n) = 8T(n/2) + n² ⇒ Θ(n³)
Case 2 f(n) = Θ(nlogb a logk n) Same growth rate (k ≥ 0) Θ(nlogb a logk+1 n) Merge sort: 2T(n/2) + n ⇒ Θ(n log n)
Case 3 f(n) = Ω(nlogb a + ε) f(n) grows strictly faster (requires a·f(n/b) ≤ c·f(n)) Θ(f(n)) T(n) = 2T(n/2) + n² ⇒ Θ(n²)
Master Theorem Inapplicability Trap

Master theorem fails when: (1) a is not constant (e.g. 2n T(n/2)), (2) b ≤ 1, (3) f(n) is not a polynomial difference (e.g. T(n) = 2T(n/2) + n/log n), or (4) regularity condition fails in Case 3.

3. Dynamic Programming Transition Formulas

0/1 Knapsack

K[i, w] =
  if w < wt[i]: K[i - 1, w]
  else: max(K[i - 1, w],
            val[i] + K[i - 1, w - wt[i]])

Matrix Chain Multiplication

m[i, j] =
  if i == j: 0
  else: min { m[i, k] + m[k + 1, j]
              + p[i-1]*p[k]*p[j] }
        for i <= k < j

Floyd-Warshall All-Pairs

D[k][i][j] =
  min(D[k-1][i][j],
      D[k-1][i][k] + D[k-1][k][j])

4. Complexity Classes & Reduction Chains

Definitions for KTU PCCST502 Part A
  • P: Decision problems solvable in polynomial time O(nk) by a deterministic Turing machine.
  • NP: Decision problems verifiable in polynomial time by a deterministic Turing machine (or solvable in polynomial time by a non-deterministic machine).
  • NP-Hard: A problem X such that every problem in NP is polynomial-time reducible to X (Y ≤p X, ∀ Y ∈ NP). X does not need to be in NP.
  • NP-Complete: A problem that is both in NP and NP-Hard. (Proved by reducing a known NPC problem to it).
