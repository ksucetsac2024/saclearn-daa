Q1 · Module 1 3 Marks

Define Big-O and Big-Omega notations with their formal mathematical definitions.

Show Model Solution & Marking Scheme

Big-O Notation: f(n) = O(g(n)) if there exist positive constants c > 0 and n0 ≥ 1 such that 0 ≤ f(n) ≤ c·g(n) for all n ≥ n0. Represents an asymptotic upper bound.

Big-Omega Notation: f(n) = Ω(g(n)) if there exist positive constants c > 0 and n0 ≥ 1 such that 0 ≤ c·g(n) ≤ f(n) for all n ≥ n0. Represents an asymptotic lower bound.

Marking Scheme: Definition and inequality for Big-O: 1.5 Marks; Definition and inequality for Big-Omega: 1.5 Marks.
Q2 · Module 1 3 Marks

Solve the recurrence T(n) = 4T(n/2) + n² using the Master Theorem.

Show Model Solution & Marking Scheme

Given a = 4, b = 2, f(n) = n².

Compute nlogb a = nlog2 4 = n².

Compare f(n) = n² with nlogb a = n². Here f(n) = Θ(nlogb a logk n) with k = 0.

By Master Theorem Case 2, T(n) = Θ(nlogb a logk+1 n) = Θ(n² log n).

Marking Scheme: Identification of a, b, f(n): 1 Mark; Computing nlogb a: 1 Mark; Final answer Θ(n² log n): 1 Mark.
Q3 · Module 2 3 Marks

Explain the role of union by rank and path compression in disjoint sets.

Show Model Solution & Marking Scheme

Union by rank: Attaches the shorter tree under the root of the taller tree during union, keeping the tree height bounded by O(log n).

Path compression: During Find(x), flattens the tree structure by making every visited node point directly to the set root.

Combined, any sequence of m operations takes nearly linear time O(m·α(n)), where α is the inverse Ackermann function.

Marking Scheme: Union by rank explanation: 1 Mark; Path compression explanation: 1 Mark; Resulting amortized complexity: 1 Mark.
Q4 · Module 2 3 Marks

How does Strassen's matrix multiplication achieve a lower time complexity than the naive method?

Show Model Solution & Marking Scheme

Standard matrix multiplication divides matrices into 8 sub-multiplications of size n/2: T(n) = 8T(n/2) + O(n²) ⇒ O(n³).

Strassen uses algebraic identities to compute 7 multiplications and 18 additions: T(n) = 7T(n/2) + O(n²).

By Master theorem, nlog2 7 ≈ n2.807, yielding Θ(n2.807) time complexity.

Marking Scheme: 7 multiplications vs 8: 1 Mark; Recurrence formulation: 1 Mark; Final complexity O(n2.807): 1 Mark.

Show Model Solution & Marking Scheme

1. Optimal Substructure: An optimal solution to the problem contains within it optimal solutions to subproblems (e.g. shortest path subpath property).

Q6 · Module 3 3 Marks

Why does Dijkstra's algorithm fail on graphs with negative weight edges?

Show Model Solution & Marking Scheme

Dijkstra operates on a greedy assumption: once a vertex is marked finalized (extracted from the priority queue with minimum distance), its shortest path distance is permanently settled.

A subsequent negative weight edge could provide a shorter path to an already finalized vertex. Because Dijkstra never re-evaluates finalized nodes, it computes incorrect distances.

Marking Scheme: Mention of greedy finalization: 1.5 Marks; Counter-example or explanation of negative update bypass: 1.5 Marks.
Q7 · Module 4 3 Marks

Differentiate between Backtracking and Branch & Bound.

Show Model Solution & Marking Scheme
  • Search Strategy: Backtracking uses Depth-First Search (DFS) with a recursion stack. Branch & Bound uses Breadth-First Search (BFS) or Least-Cost search (LCBB) with a priority queue.
  • Application: Backtracking is typically used for constraint satisfaction and decision problems (N-Queens, Sudoku). Branch & Bound is used for optimization problems (0/1 Knapsack, TSP).
  • Pruning: Backtracking uses bounding functions to stop dead branches. Branch & Bound computes estimated lower/upper bounds to prune subtrees exceeding the current best solution.
Marking Scheme: 3 valid points of differentiation: 1 Mark each.
Q8 · Module 4 3 Marks

Define the complexity class NP and NP-Complete.

Show Model Solution & Marking Scheme

NP (Nondeterministic Polynomial time): Class of decision problems for which a proposed solution certificate can be verified in polynomial time by a deterministic algorithm.

NP-Complete: A problem X is NP-Complete if: (1) X ∈ NP, and (2) Every problem in NP is polynomial-time reducible to X (X is NP-Hard).

Marking Scheme: NP definition: 1.5 Marks; NP-Complete dual conditions: 1.5 Marks.

Q9 · Module 1 (9 Marks) Part B · Module 1

(a) Trace the construction of an AVL tree by inserting keys: 10, 20, 30, 40, 50, 25. Identify the rotations performed at each step. (6 Marks)
(b) Prove that the height of an AVL tree with n nodes is O(log n). (3 Marks)

Show Model Solution & Marking Scheme

Part (a) Rotations:

  1. Insert 10, 20: Balanced.
  2. Insert 30: 10 has balance factor -2 (RR imbalance) ⇒ Left rotate at 10. Root is 20, children 10 and 30.
  3. Insert 40: Balanced.
  4. Insert 50: 30 has balance factor -2 (RR imbalance) ⇒ Left rotate at 30. Subtree root 40, children 30 and 50.
  5. Insert 25: Root 20 has balance factor -2. Right child 40 has left child 30 (RL imbalance) ⇒ Right-Left double rotation. Final tree root 30, left child 20 (with children 10, 25), right child 40 (with child 50).

Part (b) Height Proof:

Let N(h) be min nodes in AVL tree of height h. N(h) = N(h - 1) + N(h - 2) + 1. Since N(h) > Fh ≈ φh / √5 where φ = 1.618, taking logs yields h < 1.44 log2 n. Thus h = O(log n).

Marking Scheme: Correct rotations and tree states: 6 Marks; Fibonacci recurrence and logarithmic height proof: 3 Marks.
Q10 · Module 2 (9 Marks) Part B · Module 2

Explain Kosaraju's algorithm for finding Strongly Connected Components (SCC) of a directed graph. Trace it on a directed graph with vertices A, B, C, D, E and edges A→B, B→C, C→A, B→D, D→E, E→D.

Show Model Solution & Marking Scheme

Kosaraju's Algorithm Steps:

  1. Run DFS on original graph G and push vertices onto a stack ordered by finishing times.
  2. Compute transpose graph GT by reversing all edge directions.
  3. Pop vertices from stack. If unvisited in GT, start DFS from it; all reachable vertices form one SCC.

Trace on Graph:

  • Stack finish order (top to bottom): A, B, C, D, E
  • Transpose edges: B→A, C→B, A→C, D→B, E→D, D→E
  • DFS 1 on GT from A visits: {A, C, B} ⇒ SCC 1: {A, B, C}
  • DFS 2 on GT from next unvisited (D) visits: {D, E} ⇒ SCC 2: {D, E}
Marking Scheme: Algorithm steps: 3 Marks; Finishing time stack trace: 2 Marks; Graph transpose: 2 Marks; Final SCC identification: 2 Marks.

Q12 · Module 4 (9 Marks) Part B · Module 4

Prove that the Vertex Cover problem is NP-Complete by polynomial-time reducing the 3-SAT (or Clique) problem to it.

Show Model Solution & Marking Scheme

Step 1: Prove Vertex Cover ∈ NP

Given a certificate V' ⊆ V with |V'| ≤ k, verify that for every edge (u, v) ∈ E, at least one of u ∈ V' or v ∈ V'. This verification takes O(V + E) time, which is polynomial.

Step 2: Reduce Clique to Vertex Cover (Clique ≤p Vertex Cover)

Given an instance of Clique ⟨G = (V, E), k⟩:

  1. Construct the complement graph Ḡ = (V, Ē) where (u, v) ∈ Ē ⇔ (u, v) ∉ E.
  2. Set k' = |V| - k. The transformed instance is ⟨Ḡ, k'⟩.
  3. Construction takes O(V²) polynomial time.

Equivalence Proof: V' is a clique of size k in G ⇔ V \setminus V' is a vertex cover of size |V| - k in Ḡ.

Marking Scheme: NP verification proof: 2 Marks; Complement graph reduction construction: 3 Marks; Forward and backward equivalence proof: 4 Marks.
